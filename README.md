# もじを さがそう！

どうぶつたちといっしょに、ひらがなを見つける4択ゲームです。iPadのSafariでタッチして遊べます。

## 遊び方
1. 「ゲーム スタート！」を押す
2. 上に表示されたひらがなと同じ文字を4つの中からタッチ
3. 正解すると星を獲得。10問でステージクリア！

音声読み上げは端末の日本語音声機能を使用します。

## GitHub Pagesで公開
このリポジトリをGitHubにpushし、Settings → Pages → Build and deployment → Source を「GitHub Actions」に設定してください。

公開URL（リポジトリ名が `moji-wo-sagaso` の場合）:
